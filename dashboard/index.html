Rahul Ega · recorded replay · not a live cluster

I built this as a portfolio streaming project. A Python producer creates synthetic trade events (including duplicates, late arrivals, and a few broken records on purpose). Those events go into Redpanda, which speaks the Kafka API. Spark Structured Streaming reads them, checks a defined schema, sends bad rows to a dead-letter path, cleans and dedupes the good ones with a watermark, runs tumbling and sliding window aggregates, and writes bronze / silver / gold tables to Delta Lake. Gold uses foreachBatch with a Delta merge so window keys can be upserted safely on retry.

This page is not wired to a live broker. It replays metrics from a real recorded run so you can see the shape of the pipeline without installing Docker.

  • Play animates events/sec, late and malformed counts, stage progress, and window totals.
  • Pause / Reset / Speed control the replay.
  • Full code and local run steps: GitHub repo linked in the footer.

At-least-once processing with checkpoint recovery; gold merge is idempotent at the window grain. Single-node demo, simulated data, no schema registry.
